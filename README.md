# ✝本質✝ DANMAKU

小説『偏差値60の教室から✝本質✝が漏れ出している件について』をモチーフにした、ブラウザで遊べる全5ステージの弾幕シューティングゲームです。画像・音声ファイル・ゲーム用外部ライブラリは使わず、Canvas 2D と Web Audio API で描画・音響を生成します。

## 遊び方

- **WASD / 矢印キー**：移動。**Shift**：低速・精密移動
- **X**：ボム（弾消し・一時無敵）。**P / Esc**：一時停止
- **Enter**：開始・次のステージ・リトライ
- マウス・タッチ：ゲーム画面をドラッグして移動。スマートフォンでは画面下のボム・低速ボタンを使用
- 射撃は自動。弾に接近すると GRAZE ボーナス。5ステージを順番にクリアするとエンディングです。

各ステージでは、敵弾の速度・発射数・発射頻度・ボスの耐久力が単調に上昇します。敵の登場タイミングと発射パターンは再現可能で、弾幕には回避用の隙間を設けています。残機は3、初期ボムは2。ステージクリア時にボムが1個回復します（最大3個）。

## ローカルで起動

```sh
npm ci
npm run dev
```

型チェックと本番ビルド：

```sh
npx tsc --noEmit
npm run build
```

## Vercel で公開

このリポジトリのルートを Vercel プロジェクトに接続し、Framework Preset を **Vite** にします。`vercel.json` に `npm run build` と出力先 `dist` を設定済みです。環境変数・バックエンドは不要です。Vercel の Production Branch が `main` の場合は、ゲームの変更を `main` にマージすると本番 URL に反映されます。プレビューブランチでは Preview デプロイの URL に反映されます。

ゲーム本体・描画・サウンド・スタイルは `src/App.tsx` に実装しています。React はメニュー切り替えのみ担当し、毎フレームの更新は Canvas 内の固定長プールで処理します。初回操作時にブラウザの音声再生制限が解除されます。
